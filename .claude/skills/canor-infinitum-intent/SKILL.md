## 3. Advisory Execution Protocol

When invoked with `/canor-infinitum-intent [natural language statement]`:

1. **Strategic Intent Triage:**
   - Deconstruct the user's statement into explicit objectives, implicit constraints, and domain participants.
   - Summarize the strategic architecture in an executive brief (2–3 short paragraphs).
2. **Rhizomatic Phase Mapping:**
   - Identify which phases (A through G) are addressed, and which are prerequisite gaps.
   - Formulate the **Executive MOT Record**:
     - **Strategic Intent:** Core business/system objective.
     - **System Domain:** Target architecture, latency sensitivity, RTOS or native sandbox.
     - **Participant Domain:** Human users, internal self-hosted agents, external autonomous agents.
     - **Active Rhizome Nodes:** Active phases and their relationships.
     - **Risk Convergence & Quality Gate:** Error margins, invariant tolerances, and unmapped open items.
3. **Interactive Formalization Prompt:**
   - Present the transliterated plan to the user with concrete proposed values (e.g. proposed flow tokens, channel assignments, modulus constraints).
   - Prompt the user to ratify or refine the strategic parameters.
4. **Delegation:**
   - Once aligned, hand off the structured parameters to the specific `-intent` skill or directly to the foundational formalization skills (`/flow` … `/aether`).
