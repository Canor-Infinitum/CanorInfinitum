# CanorRepositorium: Project B (Storage, Learning & Runtime)

Project B implements the storage, machine learning, and runtime execution infrastructure for CanorInstinctivus. This includes FlowStore (mapping cryptographic hash identifiers to RGB content strings), lexicographical word/flow indexing, and hypervector dictionary storage.

## Role in Canor Architecture

- **Specification Authority:** Defined in `Canor_Working-Draft_v1.pdf` and this repository's Markdown specifications ([SCHEMA.md](../../SCHEMA.md)).
- **Implementation Standards:** C11 with integer-only arithmetic, fixed-width types, and canonical `canor_*` identifier naming.
