# CanorInstinctivus: Applied Theory and Practice

CanorInstinctivus integrates the CanorLinguae language suite, the CanorDatabasis invariant store, and CarmenInstinctus physical models into concrete operational workflows. It implements strategy engines, state excitation algorithms, and Ore algebraic extensions.

## Role in Canor Architecture

- **Specification Authority:** Defined in `Canor_Working-Draft_v1.pdf` and this repository's Markdown specifications ([SCHEMA.md](../SCHEMA.md)).
- **Implementation Standards:** C11 with integer-only arithmetic, fixed-width types, and canonical `canor_*` identifier naming.
