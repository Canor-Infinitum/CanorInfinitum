Inherits **all** non-negotiable rules from the [root AGENTS.md](../AGENTS.md). These local rules specialize and reinforce the global constraints:

## Local Invariants & Rules

- **Role:** CanorLinguae (QGTC) is a reactive, multi-metaprogramming language suite combining quantum-symbolic and physical models. It covers the nine layered interoperability languages: Flow, MetaFlow, Action, Soul, Maneuver, United, Elite, Follower Interlingua (Latin: Carmen), and Aether IR.
- **Local Rules:** Strict compliance with `atoms.ebnf` and Canor Working Draft sections §0–§9. Pipe-dot formatting (`|.lang ... .|`) for embedded complementary code blocks. Rate-limited ops/sec timing with $3 \times 3 \times 3$ latency and jitter fields.
- **Naming Standards:** Strictly `canor_*`. Legacy prefixes (`fc_*`, `vi_*`) are forbidden in all new and migrated code.
- **Arithmetic:** Pure integer and interval arithmetic. Floating-point types (`float`, `double`) are prohibited.
- **Status Codes:** Return unified `canor_status` with explicit diagnostics for undefined cases.
