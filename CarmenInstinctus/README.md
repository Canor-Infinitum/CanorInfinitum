# CarmenInstinctus: Physical Simulation & Discrete Quantum Relativity

CarmenInstinctus provides a plug-and-play physical modeling layer implementing a Discrete Quantum Relativity Theory Extension (Q-RT) with multiform Unruh-Lorentzian frames. It defines diffeomorphic bases, Selmer-Lie brackets, Diffeomorphic Quantum Gravity (DQG) models, and complementary-language execution adapters.

## Role in Canor Architecture

- **Specification Authority:** Defined in `Canor_Working-Draft_v1.pdf` and this repository's Markdown specifications ([SCHEMA.md](../SCHEMA.md)).
- **Implementation Standards:** C11 with integer-only arithmetic, fixed-width types, and canonical `canor_*` identifier naming.
